# 本番データセット

ここには「メーカー等の公表情報を実際に確認し、出典URL・参照箇所・確認日を記録できた」データだけを置きます。

現在の状態: **商品 0 件 / 出典 0 件 / 販売先リンク 0 件**。
記事は `articles/` に下書き（status: draft）だけがあります。

## なぜ空なのか

Phase 1 の実装環境から、メーカー公式サイト・航空会社・アフィリエイト各社のドメインへ
アクセスできませんでした（ネットワークの外部送信が遮断されています）。
計画書 5-2節「値が不明なら null。0、推定値、類似商品の値で穴埋めしない」および
「存在しない値を作って本番に混ぜない」に従い、確認できない仕様を書き込んでいません。

画面と機能の確認には `datasets/demo/`（実在しないデモデータ）を使います。
`SITE_MODE=production` ではデモデータを読み込めません。

## 埋め方

1. メーカーの公表仕様ページを開き、`sources.json` に出典を追加する（`checkedAt` は実際に見た日）。
2. `products/<category>.json` に商品を追加する。確認できない項目は `value: null` のままにする。
3. 販売先で型番・容量・バリエーションを照合し、`merchants/*.json` に登録する。
4. `npm run validate:content` を実行し、エラーが 0 件になることを確認する。

手順の詳細は `docs/operations.md` を参照してください。
